# 移动端体验评估（2026-07-24）

## 开发要点
- **总评（2026-07-24）**：移动端已具备主流 App 骨架（底栏五格、灰底白卡、暖色品牌、多频道对齐酷安），**可用性中上**；主要短板是**顶栏信息过密、频道不一致、商城演示货伤信任、拟真内容穿帮**。
- **符合移动端要求的部分**
  - 底栏：首页 / 短视频 / AI 贝拉 / 消息 / 我的；中心贝拉识别度高
  - 列表：双列卡片 + 封面 meta；声场白卡流；评论底栏贴底 + safe-area
  - 触控：多数主操作 ≥36–44px；发布 `+`、筛选抽屉、灯箱等已专项优化
  - 品牌：酒红 + 暖米体系已铺开；文档/认证/乐谱等频道有统一灰底
- **优先优化（P0）**
  1. **顶栏三层过密**（快捷入口 + 搜索 + 分类 Tab ≈134px）：首页首屏内容被压 → **2026-07-26 已上线**滚动收起快捷入口（`b2-m-banner-collapsed`）；真机手势可再调
  2. **商城 `/shop`**：演示货已下架（2026-07-24）；已上 5 个工作室服务样板 SKU（见 `studio_shop_orders_proposal.md`）
  3. **声场拟真重复帖**（同题多条）与回响种子占比高 → 已有 audit；**两组重复旧话题已下架**（见 `ops_audit_ux_dev_memory.md` 2026-07-24 清理）
  4. **底栏高亮**：非首页频道时「首页」仍 current → **已修（2026-07-24）**：仅首页/短视频/消息/我的匹配时高亮；声场/分类等频道不高亮「首页」（见 `b2_shorts_dev_memory` / child.js `syncFooterActive`）
- **次优（P1）**
  5. 首页双列卡左右边距偏紧；封面懒加载骨架偏久
  6. 文章内页有评论栏时贝拉入口弱（无底栏中心）
  7. 声场广场类型芯片（我说/提问/投票/你猜）对新人成本高，可默认收进筛选
  8. 未登录态遮罩/空态文案可更统一（少露父主题灰框）
- **可延后（P2）**
  9. 商城移动专项样式（现偏桌面主题残留）
  10. 跨页骨架屏统一品牌色（现灰块偏冷）
- **抽查页**：首页、`/circle`、`/shop`（390×844）；结合既有 mobile 记忆与 ops_audit
