## 说明

- **两套清单**：下方 `## 移动端清单` / `## 桌面端清单` **分开打勾**，禁止一行混两端。
- **用途**：逐页对照 `design_system_spec` §2 / §4 / §7；不要只标「模块 ✅」。
- **对照模板**：L 列表 · L-row 乐谱行 · R 阅读 · F 功能 · S 沉浸 · M 浮层 · T 工具。
- **过法**：元素抽取 → 对照 `element_catalog_dev_memory.md` → 改样式并部署 → 确认再下一 ID。
- **隔离**：移动规则锁 `@media (max-width: 768px)`；桌面兜底 `min-width: 769px`；桌面须无底栏/抽屉泄漏。

### 强制：逐页「元素抽象 → 对齐目录」

沟通用语：`mobile_shell_glossary_dev_memory.md`（顶栏 / 快捷入口栏 / 搜索栏 / 导航栏 / 工具栏·筛选栏·标签筛选栏 / 主页面背景色 / 列表项 / **标签栏**=底部五格）。

1. 列出本页全部元素 → 映射 `E-*` ID  
2. 对照元素目录：规范态 / 本页偏差 / 动作  
3. 改本页；新形态回写目录 + 规范 §7  
4. 「同元素待对齐页」→ 下页复用，禁止再发明一套  

### 每页最小检查项（打勾前）

| # | 项 |
|---|-----|
| 1 | 模板归属正确（非四不像） |
| 2 | 托底 `--b2-list-bg`（Shorts/写作白底等 §9 例外除外） |
| 3 | 筛选芯片：高 28、r4、冷灰 / 选中 soft+描边；条上下 pad≈4 |
| 4 | 列表项：圆角 10、卡距 10、标题/摘要/meta 字号 |
| 5 | 阅读页：H1 20 / 正文 15 / 文内 16 |
| 6 | 无父主题残色（`#ff3a55`、彩虹图标、冷灰第三套） |
| 7 | **本端**：移动无桌面面板误套；桌面无底栏/抽屉泄漏、限宽合理 |
| 8 | 本页元素分析结果已输出，目录已更新 |
