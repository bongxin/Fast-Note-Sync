# 运营拟真与文档巡检

## 开发要点
- **目的（2026-07-24）**：自动检查运营发帖与拟真行为是否「看起来假/不方便」，重点：**模仿用户行为**、**文档·平台指南**、**声场回响·反馈**
- **任务**：`/root/acappella-ops/jobs/ops_audit_ux.php`；入口 `run.sh ops_audit_ux`；已挂入 `all_daily`（在 `engage_correct` 之后）
- **输出**：仅报告不删帖；`state/ops_audit_ux_YYYY-mm-dd.json` + logs
- **检查项**
  - behavior：种子昵称音乐梗、同帖同用户多顶层 boost、boost 过密、近7日赞/浏览比异常、近7日种子话题标题重复
  - document：平台指南缺失/过少/芯片未置顶、正文过短、后台内容泄漏（排除「不包含后台」免责声明）、空文档
  - feedback：term 非公开、真实用户超时未官方跟帖（排除 bern/admin 与种子）、种子占比过高、同日种子爆发
- **连带修复（同日）**：`user_behavior.php` 扩大话术池、14 日内不重复标题、**禁止自动往 feedback 声场灌帖**
- **已知存量问题**：历史重复标题话题仍会告警，需择机手工或脚本下架旧重复；回响列表种子占比高属运营包装策略，可接受但保持 mid 告警
- **存量清理（2026-07-24）**：审计两组 `dup_seed_topic_title` 已下架重复（回收站），每组保留最早一条：
  - 「求推荐竖屏直拍账号」保留 `4759`；下架 `4790` / `4885` / `4886`
  - 「混声编曲里低音怎么稳住？」保留 `4131`；下架 `4730`
  - 仅处理 `_b2_ops_topic=1` 种子帖；未删评论（均为 0）
