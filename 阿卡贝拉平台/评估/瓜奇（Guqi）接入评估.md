# 瓜奇（Guqi）接入评估

## 开发要点
- **结论（2026-07-26）**：**主站不上、不迁移**；可本地/新站沙盒学习；与运营「站内 Agent」方向长期相关，但现阶段 ROI 不如继续 B2。
- **瓜奇是什么**：WP 插件（GraphQL）+ Node/Nuxt 前端 + 官网构建器（半 SaaS）；订阅制；构建器依赖 7b2/guaqi 官网，站点运行可不连官网。
- **官方定位**：外贸/多垂直独立站、多前端、知识付费+电商+社交；**B2 与移动端继续维护**，APP 将逐步迁到新系统；老用户可迁移但非强制。
- **成熟度**：官网约 GuaQi 2.3.x（MCP、缓存重构、多前端、商城）；文档侧栏仍多「待完成/待补全」；用户反馈缺完整搭建/构建器教程；sitemap 偶发不稳。
- **B2→瓜奇迁移**：第三方「7b2迁移瓜奇」可迁用户/分类/文章（保 ID）；**社区/商城/认证未完整迁移**（作者自述）。
- **同站并行风险**：官方建议**新站体验**；同机双栈吃内存（现网约 3.8G）；同 WP 装瓜奇插件可能与 B2 钩子冲突（官网评论曾出现头像钩子互盖）。
- **对阿卡贝拉**：练习/贝拉/语音评论/短视频二开等**不会自动出现在瓜奇前端**；MCP 与「声场+智能体」理念契合，但可先在 B2 用现有 ops/REST 闭环，不必为 MCP 换栈。
- **何时再评**：要第二品牌/出海/多独立站；或 B2 维护成本不可持续且瓜奇社区+迁移+文档成熟。
