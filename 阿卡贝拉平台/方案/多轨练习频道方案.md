# 多轨练习频道方案

## 开发要点
- **现状（2026-07-24）**：P0 **已上线** → 独立 CPT 频道 `/practice`（见 `practice_dev_memory.md`）。乐谱 `score` 仍为 PDF，与练习频道分离。
- **对标**：声部轨静音/独奏 + 跟唱练习（SATB/VP），非流行 K 歌减伴。
- **已落地 P0**：人工分轨 meta + Web Audio（mute/solo/音量/A-B）；示范曲《茉莉花》SATB + 3 首正弦波演示；快捷入口「练习」
- **后续**
  - **P1（2026-07-29 已上线核心）**：变速、耳返录音、练习打卡进声场（复制文案+开声场）；乐谱详情 CTA 跳转练习（更早已落地）
  - **P1 余量**：真人分轨曲库、会员解锁、不改调变速
  - **P2**：AI 拆轨（服务器无 GPU，暂缓）、MIDI 跟谱、打分、会员解锁- **产品形态澄清（2026-07-24）**：用户要边看 PDF 边分轨听。
  - **已落地（练习页）**：`/practice/{slug}` 同页嵌谱 + 可折叠分轨面板，播放不中断（声场反馈已优先修）
  - **未做**：乐谱详情页底部抽屉挂播放器（反向入口仍可后做）
- **真分轨内容**：后台「练习」替换合成 WAV 为真人声部分轨 mp3/m4a；注意版权；《茉莉花》已跑通产品路径
