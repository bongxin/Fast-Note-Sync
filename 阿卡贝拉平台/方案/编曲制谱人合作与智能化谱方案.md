# 编曲制谱人合作与智能化谱方案

## 开发要点
- **目标**：从「PDF 能看」升级为「谱可跟、轨可练」——结构化谱面（MusicXML/MIDI）+ 分轨音频 + 站内练习播放器。
- **为何不靠纯 OMR**：P0 已证明矢量 PDF→Audiveris 能出声，但改编谱错音率需人工校；长期应以**制谱源文件**为主，OMR 仅作存量补救。
- **合作对象**：编曲人 / 制谱人（MuseScore、Sibelius、Finale、Dorico 用户）；高校阿卡贝拉团谱库维护者。
- **向合作方要的交付包（建议标准）**
  1. MusicXML（或 `.mscz` + 导出 XML）— 分声部清晰（S/A/T/B…）
  2. 分轨音频（每声部一轨 wav/mp3；可选合轨 + 节拍轨）
  3. PDF 印刷谱（站内阅读/下载）
  4. 元数据：曲名、改编者、声部编制、调性、BPM、难度、用途=教学
- **站内落点（已有能力）**
  - 乐谱帖：PDF + meta；`score_practice=可练习` 标识/筛选
  - 练习 CPT：多轨 mute/solo；`_b2_practice_linked_score_id` 双向关联
  - 示范路径：《茉莉花》5574 ↔ `/practice/demo-molihua`
- **分期**
  - **P0 伙伴试点**：找 1–2 位制谱人，按交付包上 3–5 首；人工挂练习轨 + 可练习标
  - **P1 后台半自动**：上传 MusicXML/分轨 → 自动建练习曲、写关联、打「可练习」；可选 MIDI 跟谱高亮（后置）
  - **P2 激励**：改编者署名页、分成/积分、精选「可练习」专区、会员解锁高阶谱
- **对编曲人话术要点**：一次制谱，多端复用（PDF 阅读 + 分轨练 + 将来跟谱）；署名保留；教学用途表述降低版权摩擦
- **不做**：承诺任意扫描 PDF 自动完美识谱；无源文件时强行全站 OMR
