# 模拟广告 / 广告投放方案

## 开发要点
- **已落地（2026-07-24）**：子主题广告投放管理，非 B2 空 HTML 广告位。
- **三处槽位**
  1. `home_feed` — 首页推荐信息流（每 N 条插 1）
  2. `archive_feed` — 分类/标签列表信息流（乐谱表格页跳过）
  3. `single_bottom` — 文章详情正文底部横幅
- **后台**：WP 菜单「广告投放」CPT `bern_ad`（标题 / 特色图封面 / 链接 / 副文案 / 投放位多选 / 优先级）；子菜单「投放设置」（总开关、间隔 every_n 默认 10、角标文案默认「广告」）
- **素材**：运营在后台新建并**发布**；无封面的广告不投前台（方便先建草稿）
- **角标**：前台强制酒红底白字「广告」（或设置中的文案），左上角明显展示；链接 `rel=sponsored`
- **实现**：`functions-ads.php` + `assets/ads.css` + `child.js` `initFeedAds`
