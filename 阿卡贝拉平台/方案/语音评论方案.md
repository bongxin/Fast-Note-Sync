# 语音评论方案

## 开发要点
- **已确认并落地（2026-07-24）**：直接做 **P0**；覆盖 **文章 + 声场 + 短视频**；交互为 **按住说话**（上滑取消）。
- **实现**
  - REST：`POST /wp-json/b2child/v1/voice-comment`（multipart `audio` + `post_id` + `parent` + `duration`），须登录
  - Meta：`b2_voice_url` / `b2_voice_id` / `b2_voice_duration`；正文占位 `[语音]`（列表隐藏）
  - 复用父主题 `Comment::submit_comment` 写评论；`rest_post_dispatch` 给 `commentSubmit` / `getTopicCommentList` / `getChildComments` 注入 `voice`
  - 文章 SSR：`b2_comment_text` 钩子输出气泡；声场：子主题覆盖 `TempParts/circle/circle-comments.php`
  - 前台：底栏麦克风钮 + 抽屉内「按住说话」；短视频侧栏「语音」→ 同一 overlay
  - 格式探测：优先 `audio/mp4`，再 `webm`；限时 60s、约 5MB
- **录音抽屉 UX（2026-07-24）**：贴底全宽 sheet（盖住底栏）；按钮改麦克风图标（去掉重复「按住说话」）；录音中波形动画；文案分态 idle/recording/cancel/uploading；tip 留足底 padding；发送成功刷新「共 N 条评论」
- **底栏语音钮（2026-07-24）**：去掉实心酒红/棕色圆 + 易看成「0」的 CSS 胶囊；改为与赞/评同系的线框 SVG 麦克风（透明底、灰字色）
- **桌面端语音（2026-07-24）**：居中卡片弹层；点击麦克风开始 / 再点或「发送」提交；「取消」+ Esc；入口并入 `.com-form-button-l`（与表情/图片同排），隐藏表单下方孤立「发语音」行
- **移动端确认发送（2026-07-26）**：仍按住说话 + 上滑取消；**松开不直发** → `is-preview` 出「取消 / 发送」（`pendingUpload`）；桌面录音中按钮逻辑不变
- **评论工具条统一（2026-07-26）**：
  - 表情 / 图 / 语音 = 同尺寸 36 透明线框钮；提交 = 唯一酒红实心胶囊
  - 表情图标固定 `b2-emotion-line`；移动抽屉面板向上弹出（见 `single_mobile_density`）
  - **图片预览（2026-07-26）**：`.comment-image-box` 勿跟表情共用 230×102；改为 120 方图 `object-fit:cover`，移动常显更换/删除
  - 文章评论：语音并入 `.com-form-button-l`，**去掉**棕底「按住说话」整行与粉底芯片
  - 隐藏 `.comment-type`（涂鸦/文本粉角标）；图片钮用 **`b2-image-fill`**（勿 `landscape-line`；勿再注自定义 SVG 盖住 iconfont）
  - 输入区两端统一暖灰 `#f5f3f2`；兜底 hold 钮仅无工具条时用浅红描边次钮
- **桌面语音钮布局（2026-07-28）**：文档页曾未套 `single-post` 工具条规则 → 表情仍 `margin-right:20`、语音 36 白底灰框不齐。修：`voice-comment.css` 桌面 `#comment-form .com-form-button-l` 统一 36 透明居中 + 压父主题 button；`style.css` 同步扩到 `single-document`；部署 `_deploy_voice_tool_layout.py`
- **移动端入口收敛（2026-07-26）**：
  - 发表评论面板**不再**显示语音钮；仅底栏 `.b2-m-comment-bar__voice`
  - 图标：移动=`voiceWaveSvg` 声波柱；桌面=`voiceMicSvg` 原线框麦克风；录音垫随端切换
  - 轻点未按住：`releasedBeforeStart` → getUserMedia 回调立刻 toast「说话时间太短」（旧逻辑松手早于 recorder 就绪会吞掉第一次）
- **语音层 z-index（2026-07-26）**：`.b2-voice-overlay` = **100040**（> 评论抽屉 100020）；录音中评论抽屉/遮罩 `pointer-events:none`
- **交互分端（硬约定）**：
  - **桌面** `isDeskVoice()`：`onPadClick` 点按开始/结束；录音中「取消/发送」
  - **移动**：`onPadDown/Up` **按住说话** + 上滑取消；松手 → preview「取消/发送」；**禁止**改成点按录音；`onPadClick` 移动 early-return
- **微信同款声波（2026-07-26）**：`voiceWaveSvg` 改为 4 根圆角竖条线框（`stroke` + `round`），比例对齐微信聊天输入栏语音切换；底栏 22；**勿**喇叭弧线、勿均衡器乱高
- **录音层去重（2026-07-26）**：垫钮统一 `voiceMicSvg`；上方 `__wave` 条空闲隐藏，仅 `is-recording`/`is-cancel` 显示动画（勿空闲再摆一排静态声波与垫图标重复）
- **侧栏最新评论空正文（2026-07-26）**：`comment_text` 滤掉 `[语音]` 后 `getNewComments` 的 `content` 为空。修：`rest_post_dispatch` 拦截 `/b2/v1/getNewComments`，按 `#comment-ID` 补 `<span class="b2-widget-voice-label">语音 N"</span>`；文章评论区仍只显示气泡
- **坑**
  - 微信/iOS 麦克风权限与 MIME；HTTPS 必需
  - 勿深改父主题 Vue；列表字段靠 REST 注入 + 子主题模板
  - Shorts 沉浸页无评论列表，发送成功仅 toast；完整气泡在「查看详情」评论区可见
  - 桌面 `startRecord` 勿看 `pressPending`（走 click）
  - 语音 overlay z-index 勿再压回 10050，会被发表评论抽屉挡住
- **未做（后续）**：ASR 转写、语音审核工具
