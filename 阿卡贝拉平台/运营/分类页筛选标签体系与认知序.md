# 分类页筛选标签体系与认知序

## 开发要点
- **分类页顶栏严重抖动鬼影（2026-07-28）**：音乐人等分类页「用着用着」顶栏/筛选条纵向鬼影。根因：工具条吸顶后 `padding-top` 收起↔展开会触发微 scroll；旧逻辑 lock 内 `|dy|>4` 即可打断 + 吸顶态用普通 showGate 展开 → 过渡期内反复 toggle `b2-m-chrome-collapsed`。修：`b2-m-chrome-motion` 期间禁止再切（仅 y≤topShow 展开）；吸顶+已收起展开门槛 ×2.5（≥36px）；lock 打断阈值 4→28；分类 lock/pulse 对齐 ~340/320ms
- **无独立自定义 taxonomy 做筛选维度**：筛选几乎全是 WP 原生 `category` + `post_tag`（乐谱例外用 post meta）；另有 B2 `collection` 专题能力但主分类筛选未用。
- **配置来源优先级**（`Archive::get_fliter_data`）：
  1. 主题选项 `template_fliter` → `fliter_group`（`show=1` 且 `cat` 含当前 term_id）优先
  2. 否则分类 term meta `b2_filter`
- **标签行格式**：`维度名|标签A,标签B,...` 多行；渲染为 `?tags1=`…`?tagsN=`（`get_term_by('name')`，不存在的标签**静默不显示**）
- **分类行**：`b2_filter[0][cat]` = 子分类 ID 列表 → 改 path `/category/{parent}/{child}/`
- **乐谱例外**：`meta` 字符串 `显示名|meta_key|显示=值,...` → `?arrange=` / `?perform=` / `?voicepart=`
