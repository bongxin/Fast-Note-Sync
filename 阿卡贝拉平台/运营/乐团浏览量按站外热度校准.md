# 乐团浏览量按站外热度校准

## 开发要点
- **动机**：目录默认 `post_order=views` 后，旧伪随机浏览量与真实热度倒挂（如粉丝极少的团顶栏、MayTree 反而靠后）。
- **信号**：乐团正文官方账号区块里的 B 站 UID → `api.bilibili.com/x/relation/stat` 粉丝数；无号/国际团用 `MANUAL_TIER` 弱补；**以粉丝为主**（国际团 manual 仅 ×0.12）。
- **映射**：按 hotness 降序赋 `views`：约 **48000→120** 幂曲线（^1.65）+ 稳定噪声；meta：`_b2_ops_band_views_calibrated`、`_b2_ops_band_bili_followers`、`_b2_ops_band_hotness`。
- **坑**：团文常只挂子分类，`has_category('band')` 会漏 → 须 `band` + `get_term_children`。
- **范围**：仅 `band` 树；未动乐谱/音乐人/组织（可另开）。
- **复跑**：线上周更 **`run.sh band_hotness`** → `jobs/band_hotness_weekly.py`（自包含 dump/粉丝/计划/写回）；本地一次性脚本仍可用 `_dump_band_views.py` → `_fetch_band_hotness.py` → `_calibrate_band_views.py`。
- **Cron**：每周一上海 **04:30**（`crontab.fragment` / `install_cron.sh`）；`OPS_DRY=1` 可空跑。
- **坑（CLI）**：临时 PHP **禁止变量名 `$wp`**；须走 `lib/wp_boot.php`。
- **验收（2026-07-26）**：Top 含 MayTree → Resound → Rc过山车 → PTX → VoicePlay → Narin → 厦门六中 → 燃点…；103/103 已写；周更试跑 `changed=0`（幂等重算一致）。
