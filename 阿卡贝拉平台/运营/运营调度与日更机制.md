# 运营调度与日更机制

## 开发要点
- **运营宗旨**：发现序/筛选序定时校准须服从 **贴合用户认知**（`ops_cognition_principle_dev_memory.md`）；总账 `platform_cognition_map_dev_memory.md`
- 根目录（**非 webroot**）：`/root/acappella-ops/`；本地镜像 `_ops_pack/`
- **时区**：任务统一 `TZ=Asia/Shanghai`；**服务器系统时区是 UTC**
- **Cron（2026-07-24 修正）**
  - 必须设 `CRON_TZ=Asia/Shanghai`（`install_cron.sh` / `crontab.fragment`）
  - **坑**：只在命令前写 `TZ=Asia/Shanghai` **不够**——cron 时刻仍按系统 UTC 解析，`30 2` 会变成上海 **10:30**
  - 每天上海 `02:30` → `all_daily`：security → ingest → publish_daily → user_seed → avatar_pool → **team_mission** → **seed_mission** → user_behavior → engage → engage_correct → **ops_audit_ux** → **qa_reindex**
  - 每天上海 `18:30` → **moments_hook**：changelog/当日公告 → 朋友圈海报+文案（`queue/moments/日期/`）；见 `moments_hook_dev_memory.md`
  - 每周一上海 `03:00` → `all_weekly`：band_queue → publish_weekly → content_queue → **recruitment_hook**
  - 每周一上海 `04:30` → **band_hotness**：B 站粉丝校准乐团 `views`（`jobs/band_hotness_weekly.py`）；见 `band_views_calibration_dev_memory.md`
  - 每周一上海 `05:15` → **views_realism**：乐谱/音乐人/组织/赛事/媒体/教程 views（`jobs/views_realism_weekly.py`）
  - **每日**上海 `05:45` → **filter_tags**：分类筛选 + 快捷入口 taxonomy 序；乐团子分类行政区划自动入列；年份新→旧（`jobs/filter_tags_cognition_weekly.php`）
  - **每日**上海 `05:48` → **list_meta**：列表卡片 post_meta 认知矩阵校准（`jobs/list_meta_cognition.php`）
  - **每 4 小时** → **menu_tips**：稀疏快捷入口角标刷新（`jobs/menu_tips_refresh.php`）；亦挂在 `all_daily` / `all_weekly`
  - 每周一上海 `05:50` → **cognition_pack**：搜索/标签云热实体 + 练习 menu_order（`jobs/cognition_pack_weekly.py`）
  - 每周一上海 `09:00` → **recruitment_hook**（入驻周更私信包，幂等；人工发送）
  - 总账：`platform_cognition_map_dev_memory.md`
- **本机 Windows 定时（Obsidian）**
  - 每日 10:00 → `BERNSINE_ObsidianDocsSync`：方案/运营文档同步进 Vault；见 `obsidian_vault_sync_dev_memory.md`
  - 每周一 09:00 → `BERNSINE_RecruitmentWeekly`：入驻私信包写 Vault（与上独立）
- **主创团队每日签到（2026-07-24）**：`jobs/team_mission_daily.php`；用户取自页脚小工具 `widget_b2-widget-team` 的 `team_arg`（现 1,6,7,8,9），可用 `OPS_TEAM_IDS` 覆盖；调用 `B2\Modules\Common\User::user_mission()`；当日已签跳过；状态 `state/team_mission_day.json`；手动：`run.sh team_mission`
- **种子用户适当签到（2026-07-26）**：`jobs/seed_mission_daily.php`；排除主创；约 20%「习惯签」（~85% 日子到）+ 其余「偶发签」（~30% 日子）；日上限默认 18；状态 `state/seed_mission_day.json`；`run.sh seed_mission`；`OPS_SEED_MISSION_DISABLE=1` 可关
- **贝拉知识库日更**：`jobs/qa_reindex_wp.php` = 后台「全文重建索引」；插件侧另有 WP-Cron `acappella_qa_reindex_wp_daily`（约 04:10），若 20h 内已重建则跳过
- **短视频/视频日更（2026-07-24 起硬改）**
  - **不再**依赖 `pool/media` 或 `feeds/*/shorts|videos`
  - `publish_daily` → `jobs/crawl_publish_media.py` → `publish_crawled_media.php`
  - 发现：B站 `search/all/v2` 关键词 + 站内已发 BVID 的 `archive/related`；校验：`web-interface/view`（竖屏≤180s→短视频，横屏≥30s→视频）
  - **坑**：`space/arc/search` 易 412/-799，勿再当主力；抖音 ies 接口常空，失败不阻断（B站补齐）
  - 账号配置：`config/media_sources.json`；状态：`state/media_crawl_last.json`
  - 额度仍受 `OPS_SHORT_MAX` / `OPS_VIDEO_MAX`（默认各 20）
- **推荐页日更（硬约定 2026-07-24）**
  - 首页「推荐」按 `post_date` 排序；仅 bump `modified` / 只刷乐团不够
  - `publish_daily`：`OPS_RECOMMEND_MIN`（默认 8）— 新发短视频/视频/乐谱不足时，把旧稿（short/video/score）`post_date` 推到今日；meta `_b2_ops_recommend_refresh`
  - 日期用 `DateTimeImmutable Asia/Shanghai`，**禁止** `current_time('timestamp')` + `wp_date` 叠用（会 +8h 变「未来稿」被查询丢掉）
  - **乐团 refresh 只 bump `modified`，禁止改 `post_date`**（乐团是目录页，走「乐团」Tab；改日期会抢推荐顶栏）
  - **推荐模块约定（常规内容流 2026-07-24）**：`b2_template_index` key=`new` 的 `post_cat` = short/video/score/saishi/tutorial；**不含** band/musicians/organization；子主题 `b2child_home_recommend_loop_args` 再 NOT IN 目录类 + `ignore_sticky_posts`
  - 备份：`/root/acappella-ops/backups/b2_template_index_*_recommend_content_feed.json`
- **空池坑**：`pool/*/batch_*.json` 若为 `[]`，旧逻辑会当成一条空对象 → `media:missing_fields`；已修 `ingest_daily` / `ops_pool_json_items`
- **快报实质内容（2026-07-24）**：禁止再发「站内持续更新…」空壳。`lib/express_digest.php` 汇总近 N 天演出/赛事/作品/乐谱/视频/短视频/招募；`publish_daily` / `ingest_daily` 兜底改走 digest；不足 2 条则跳过不发。历史空壳用 `_backfill_express_digest.php` 回填。
- **快报链接（2026-07-24）**：条目必须写 `<a href>`，禁止裸 URL（否则 autoembed → `post.html/embed` nginx 404）。存量重写：`jobs/_rewrite_express_links.php`。permalink 含 `.html` 时子主题修 `post_embed_url` → `?embed=true`。
- **目录**：`feeds/` 当日抓取；`pool/{newsflashes,media,documents,links,scores}/` 素材池；`secrets/seed_users.json`（chmod 600）
- **额度（可 env 覆盖）**
  - 快讯 ≥1 / 上限 5；短视频 ≤20；视频 ≤20；乐谱 ≤10；乐团 ≤10
  - 文档完善 ≥5；导航 ≥2；专栏日挂载 ≥1；推荐可见 ≥8（`OPS_RECOMMEND_MIN`）
  - **种子用户上限约 40**（`B2_USER_SEED_MAX=40`，日增默认 2）；声场话题 **0～2/日**（`OPS_TOPIC_MIN/MAX`）
  - 周：公告 ≥1、新专栏 +≥3 文、新声场 +3 话题
- **拟真行为约定（2026-07-22 确认）**
  1. 种子规模维持约 40 人，不再冲量到数千
  2. 声场每天 0～2 条真实感发言（去掉「社区打卡日期」尾巴）；约 35% 种子当日活跃、每人 1～3 次轻互动
  3. 历史已刷赞/评允许**极慢修正**：`engage_correct.php` 默认每日最多删 2 条 boost 评论、削 1 个过高赞；只动 `b2child-engage-boost/1.0` 评论与可识别种子赞；`OPS_CORRECT_DISABLE=1` 可关
- **来源策略**：抓取/站内事件 → pool → 受控模板；乐谱无池则跳过不造 PDF
- **用户**：可登录 `subscriber`；邮箱 `*@ops.acappella.bongxin.com.cn`；密码在 `secrets/seed_users.json`；头像优先线描池 / `brand_v3`；meta `_b2_ops_seed_user=1`
- **头像规则（重要）**：仅对**未主动上传**头像的用户自动分配统一风格；判定：`_b2_ops_avatar_att` 与当前 `wp_user_avatars.media_id` 一致、或附件标题 `ops avatar*`、或路径含 `ops-avatars` → 系统头像可覆盖；否则有头像 URL/附件则视为用户自传，**禁止覆盖**（`ops_user_has_custom_avatar` / `ops_assign_styled_avatar` 默认跳过）
- 重生成头像：`php /root/acappella-ops/jobs/regen_avatars.php`（需 `fonts-wqy-microhei`）；会跳过自传用户；`OPS_AVATAR_ALL=1` 可扫全站无自传用户
- **自动文标记**：`_b2_ops_auto=1`、`_b2_ops_source`；声场话题 `_b2_ops_topic=1`（空标题 + `b2_auto_title=1`，避免标题/正文重复）
- **库**：`lib/wp_boot.php`、`dedupe.php`、`publish.php`、`avatar.php`
- **坑**：CLI 禁止变量名 `$wp`；须预设 `REMOTE_ADDR`；幂等看 `state/*_day.json` / `publish_weekly.json`（周键用 `o-WW`）
- **用户评论数**：勿把运营补评均摊给所有人（会全站 30+ 条显得假）。`comment_agent=b2child-engage-boost/1.0` 应用长尾作者；工具 `_ops_pack/tools/rebal_user_comments.py`（先按帖保留 1–5 条再 zipf 分配）。日后 `_boost_engagement.py` 的 `b2_pick_users` 已改加权抽样
- **系统头像池**：黑白线描半身（团队同款）`b2child-avatar-pool`；见 `avatar_pool_dev_memory.md`；`avatar_pool_ensure.php` + 注册自动分配
- **验收 2026-07-22**：ingest ok；publish_daily 发快讯 4108 + 乐团 refresh10 + 文档 improve5 + 链接2；user_seed 430–439 带头像；behavior 话题 4129–4132；weekly 公告 4133 / 专栏 term 1278 / 声场 1279；avatar pool 160 预制并回填 83 默认头像用户
- **媒体补发 2026-07-22 下午**：当日 `pool/media` 空导致 publish_daily shorts/videos=0。手动从 B 站空间拉未发稿 → 短视频 10（4246–4264）+ 视频 10（4267–4285，VoicePlay 横屏）；封面 sideload；`state/publish_media_manual.json`
- **乐谱**：无新合规 PDF 池则勿造谱；同日将 8 篇既有乐谱 `post_date` 刷新到今日以填充分类流（`_b2_ops_score_refresh`）。要真正新乐谱需投放 `pool/scores/*.json`
- **乐谱批量补发（2026-07-22）**：本地 `D:\BaiduNetdiskDownload` PDF 去重后新发约 80 篇；详见 `score_publish_dev_memory.md`
- **坑**：B 站 search/部分 space 易 412/-799；`x/space/arc/search` + cookie 偶发可用；单条 `x/web-interface/view` 较稳。日更已跑过需补媒体时用独立脚本，勿只靠清 `publish_daily.json` 重跑（会重做快讯等）
- **补跑 2026-07-24 03:05**：因 cron 时区错位今日未到点；手动 `all_daily` + 推荐视频日期刷新；cron 已改 `CRON_TZ`
- **漏发 2026-07-26 / 27（已修 07-27 14:26）**：两天曾无新稿；根因 `security_harden` 误隔离 `wordfence-waf.php` → exit 2 → `run.sh set -e` 掐断日更。已部署：① `security_harden.sh` ALLOW 含 `wordfence-waf`；② `run_security` 对 exit 2 记日志并 **return 0**（ALERT 不阻断 publish）。补跑 `all_daily`：07-27 短视频2+视频8（另 bands refresh）；**07-26 仍空**（未倒填日期）。烟测：harden → `RESULT=OK` 且 waf 仍在。
