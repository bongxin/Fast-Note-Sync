# 种子用户签到拟真

## 开发要点
- **分工**：主创（页脚 team）→ `team_mission_daily.php` **全员每日签**；其它 `_b2_ops_seed_user=1` → `seed_mission_daily.php` **抽样签**
- **拟真**：约 20% 习惯签（日缺席 ~15%）+ 其余偶发签（日概率 ~30%）→ 约四成非主创当日签；`OPS_SEED_MISSION_MAX` 默认 18
- **API**：同主创，走 `User::user_mission()` + `$b2_current_user_id`；已签跳过
- **日更顺序**：`all_daily` 里 team_mission → **seed_mission** → user_behavior
- **开关**：`OPS_SEED_MISSION_DISABLE=1`；比例 env：`HABIT_PCT` / `HABIT_MISS` / `CASUAL_PCT`
- **状态**：`state/seed_mission_day.json`

## 改动涉及的文件
- `_ops_pack/jobs/seed_mission_daily.php`
- `_ops_pack/run.sh`（`seed_mission` / `all_daily`）
- `_ops_pack/jobs/_deploy_seed_mission.py`
- `dev_memory/ops_scheduler_dev_memory.md`
