列表 `b2_group.post_custom_key`：改编/演唱/声部结构/难度/语种/人声组合/用途
回填约定（2026-07-22）：voicetype←声部字母；format 默认 PDF；style 按标题关键词；**用途统一 `教学`**（避免版权纠纷表述；旧约定「入门→教学、其余演出」已废止）；6 声部及以上或稠密声部→高阶
**难度重评（2026-07-28）**：不再按文件名 `Ns` 盲标。对照 PDF 文本 + 校正后 `voicepart`：
- **入门**：≤3 声部（如 SAT），或短页简易曲（生日快乐/Deck the Hall/牧歌等）且简易信号足够
- **进阶**：常规四声部 SATB/TTBB/SSAA 流行改编（默认大多数）
- **高阶**：≥5 有效声部（SATBB/SATTB/SSATB/SMATBB/TTTBB…），或 6+ / 稠密编制，或长谱+大量 solo/VP
- 标记 `_b2_difficulty_reeval=pdf-2026-07-28`；脚本 `_reeval_score_difficulty.py` / `_apply_score_difficulty.py`；结果 `state/score_difficulty_reeval.json`
**可练习（2026-07-24）**：`score_practice=可练习` 由关联 practice 分轨自动写入；筛选 URL `?score_practice=可练习`；见 `score_practice_link_dev_memory.md`

## 排序约定
- **地区**（音乐人/机构）：一线城市 → 省区（华北→东北→华东→中南→西南→西北）→ 港澳台 → 海外国别 →「海外」
- **乐团地区子分类**：推荐、高校 → 一线城市 → 其它城市/省区 → 港澳台 → 海外
- **学校/院校**：按城市圈与常见院校层级（京沪 → 华东 → 华中 → 华南 → 西部/东北 → 港澳台 → 海外）；未入序表的按拼音排末尾
- **认知热度重排（2026-07-26 日更 `filter_tags`）**：① 全站筛选按认知序；② 站内新标签/子分类自动并入再排。年份新→旧；地区走行政区划表；语义维 FIXED；实体维 heat。见 `ops_cognition_principle_dev_memory.md` / `taxonomy_filters_dev_memory.md`
- **维度行序（2026-07-26 IA）**：先决条件维靠前、长实体列表靠后；乐谱例：声部结构→难度→人声组合→语种→风格→用途→谱面格式→练习→改编→演唱。完整表见 `ia_nav_sort_dev_memory.md`；由 `$DIM_ORDER` 日更保持
