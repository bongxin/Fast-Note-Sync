# 从业者产品诉求（排练闭环 P0）

## 开发要点
- **来源**：站内从业者视角（阿卡贝拉教育/推广/演出 + 移动互联网）主动提需，非用户工单。
- **原则**：优先补「排练闭环」与「找团找人」摩擦；少造新内容库，多把现有乐谱/练习/声场/入驻串成周习惯。

### P0 想要（高杠杆、可排期）
1. **练习曲库扩真人分轨**：合成轨只证明产品；团长真正用的是 3～8 首热曲真人 SATB/VP。对接已有「可练习」标 + 制谱合作包。
2. **乐谱筛选按排练心智**：声部编制（SATB/SSAA/TTBB/混合）、难度、用途（赛场/团建/教学）、有无可练习——比纯浏览序更贴近开排前选型。
3. **「本周练什么」轻入口**：首页或练习归档一条运营位，链到 1 首示范/热曲 + 打卡；降低「进来不知道干嘛」。
4. **团页 → 招新/排练需求一键贴声场**：入驻指南已有，差低摩擦动作（模板话术 + 跳转发布）。
5. **排练清单/收藏夹**：把乐谱+练习曲钉成「我的本周歌单」，手机排练场最刚需（可先本地/用户 meta，不必完整播放列表产品）。

### P1 想要（体验与留存）
6. **练习页：不改调变速**（时间拉伸）——现有 playbackRate 变调，慢练听感差。
7. **练习打卡直发声场**（API）——现复制文案+开页，少一步才像「打卡社区」。
8. **按声部找人**：音乐人/用户标签强化（S/A/T/B/Beatbox/编曲），服务组团与客串。
9. **演出/排练日历轻聚合**：赛事已有；补「本市本月有啥」或团页活动条，利于线下回流。
10. **微信内「练完分享卡片」**：曲名+声部+进度，朋友圈钩子对齐现有 moments 自动化。

### P2 / 观察后再做
11. MIDI/跟谱高亮、打分——等结构化谱源多了再做。
12. 小程序轻壳——等网页信任转化数据再触发（路线图 Phase 3）。
13. 贝拉静默直发——坚持草稿+确认，勿静默。

### 意见（产品/运营，不一定写代码）
- 平台差异化应钉在「谱可练 + 团可入 + 声场有人回」，不要和短视频平台比时长。
- 冷启动少造热闹评论，多保证回响·反馈 24h 有人；团长认领后给「第一周练什么」包。
- 高校团开学季（9 月）是招新与练习曲库的自然窗口，内容与功能应提前 2～4 周备好。
