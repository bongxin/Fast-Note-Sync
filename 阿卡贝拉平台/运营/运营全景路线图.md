# 运营全景路线图

## 一句话
**站内声场 + 智能体 = 运维中枢；微信管信任与承接；抖音/B站管曝光；网页/小程序壳同一套数据。**

**全日定稿报告**：`ops_discussion_report_20260724_dev_memory.md`（用户要求妥善记住）

## 核心理念（必须遵守）
详见 `ops_channel_strategy_dev_memory.md`。摘要：
1. 分析 / 发布 / 回复尽量只在站内完成（声场优先）
2. 飞书、订阅号不当运维大脑；服务号只做登录
3. 小程序若做 = 信任轻壳同源，不另建内容库
4. 抖音系 = 获客喇叭，不建第二客服现场

**另：贴合用户认知**（与渠道并列的重要运营宗旨）——站上发现序/筛选序/热度须符合用户心智预期；宗旨全文与决策优先级见 **`ops_cognition_principle_dev_memory.md`**；落地总账见 `platform_cognition_map_dev_memory.md`。

## 用户漏斗（完整一条）
```
曝光（朋友圈 / 抖音 / B站切片）
  → 承接（企微名片 / 1～2 个核心群 / 服务号菜单）
  → 信任入口（网站微信内打开 或 未来小程序轻壳）
  → 注册登录（服务号 OAuth）
  → 站内活跃（新手村内容 / 声场发帖评论 / 作品与乐谱）
  → 深度转化（团认领入驻 / 创作者认证 / 回响·反馈共建）
  → 再分发（站内短视频 → 外发抖音/B站 → 简介回流）
```
运维动作集中在「站内活跃」与「深度转化」两环；外环只做触达与导流。

## 角色分工
| 面 | 担什么 | 不担什么 |
|----|--------|----------|
| **网站 + 声场** | 内容沉淀、社区互动、Agent 分析/发帖/回复 | — |
| **服务号** | 微信登录、可选菜单入口 | 图文日更 |
| **运营微信号朋友圈** | 钩子与提醒，带明确动作 | 唯一客服场 |
| **企微 + 群** | 承接、反复触达、导回站内 | 替代声场讨论 |
| **小程序（可选）** | 微信内信任与可发现 | 独立运营后台 |
| **抖音号** | 短视频曝光、简介回流 | 评论区主客服、抖音小程序重度 |
| **B站** | 作品分发 + 站内嵌入/日更抓取主力 | 运维中枢 |
| **订阅号 / 飞书** | 缓或不做 | 运维日历中枢 |

## 阶段节奏（对齐商业计划冷启动 0–6 月）

### Phase 0 — 地基（已部分完成）
- 新手村、兴趣标签、回响·反馈声场、平台指南与共建公告
- 微信登录/分享、短视频嵌入、媒体日更、反馈巡检雏形
- **跳过**：抖音评论区 AI 解析

### Phase 1 — 闭环与承接（当前优先，约 4～8 周）
1. 企微客服就绪；建新手群（+可选团长群）
2. 朋友圈统一「钩子 → 具体站内页/声场」，不再裸推首页
3. **朋友圈钩子自动化（2026-07-24 已建）**：changelog → 海报+文案日更；见 `moments_hook_dev_memory.md`
4. 声场节奏：每周 ≥1 官方话题；回响·反馈 24h 内官方/bern/Agent 回复
5. 加强 Agent：巡检 → 分析 → 回复/记记忆（延续 `feedback_circle_track` / `workflows`）
6. 内容：站内 PGC/精选为主；同一素材可同步朋友圈（自动化产出，人工发出）

### Phase 2 — 增长与入驻（约 90 天窗口，可与 Phase 1 后半重叠）
- 高校团 / 社会团认领与建档；创作者认证（见 `recruitment_onboarding_plan`）
- KPI 参考：90 天认领/新建团页 ≥20；认证创作者 ≥30；友链 ≥10
- 抖音号启动：站内优质短视频外发，简介导回；不养评论客服班底

### Phase 3 — 信任壳（按转化证据触发）
- 若网页信任明显拖转化 → 服务号复用资质注册小程序轻壳（同源数据）
- 认证费：企业约服务号/小程序各 300/年；复用可免小程序首年；企微认证约 300/年可选
- 仍不把运维搬出站内

### Phase 4 — 商业化（6～12 月后视数据）
- 会员/乐谱/演出等变现；订阅号「周精选」仅作同步可选
- 仍遵守：外部渠道不替代声场 Agent 中枢

## 周更最小动作清单（Phase 1）
- [ ] 站内可传播内容 1～2 篇（或短视频入库）
- [ ] 声场 1 个官方话题 + 官方在场回复
- [ ] 回响·反馈巡检与跟帖（Agent）
- [ ] 朋友圈：确认当日 `queue/moments/日期/` 海报+文案已生成并人工发出
- [ ] 私信/群触达若干团或创作者（入驻 Phase 2 加重）

## 明确不做（冷启动）
- 飞书/Notion 建成运维中枢（可临时草稿）
- 服务号/订阅号日更当主内容场
- 独立内容库的小程序或抖音小程序
- 抖音评论区主客服 / 评论 AI 解析（阶段一已跳过）
- 拟真种子冲刷回响·反馈场（见 `ops_behavior_policy`）
