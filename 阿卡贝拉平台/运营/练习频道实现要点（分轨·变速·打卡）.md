# 练习频道实现要点（分轨·变速·打卡）

## 开发要点
- **独立频道**：CPT `practice`，归档 `/practice`，单曲 `/practice/{slug}`；分类 taxonomy `practice_cat`（rewrite `practice-cat`，避免与 CPT slug 冲突）
- **P0 能力**：人工声部轨 URL → Web Audio 多轨；静音 / 独奏 / 音量 / 进度 / A-B 循环；移动端须点「点击开始练习」解锁 AudioContext
- **同页看谱（2026-07-24）**：有关联乐谱且能解析 PDF 时，练习页内嵌 PDF Embedder；「曲目信息 / 分轨练习 / 乐谱」可独立折叠；顶栏「看谱」展开谱面且**不跳页**（Web Audio 不中断）；进度条 sticky；「乐谱详情」新开标签。解析：`b2child_score_extract_pdf_url()`（shortcode/区块/附件/下载 meta）
- **指捏缩放（2026-07-24）**：复用文档频道 `enablePdfPinchZoom`；练习页展开乐谱 /「看谱」时经 `b2childPolishPdfEmbeds` 重挂；iframe `load` 补挂；提示「双指捏合缩放」；`practice.js` 依赖 `b2-child`
- **数据**：post meta `_b2_practice_stems`（JSON：bpm/key/voicetype/stems[]）；可选 `_b2_practice_linked_score_id` 关联乐谱文章
- **入口**：快捷顶栏「练习」（自动写入含「文档/快讯」的菜单，option `b2child_practice_menu_added`）；**不占**底栏五格
- **快捷频道壳**：PHP/JS/`b2-m-shortcut-section` + boot 灰底已含 `practice`
- **示范曲《茉莉花》（2026-07-24）**：公版民歌 + SATB；音色 **v2** 柔和管风琴垫底（少泛音、无颤音）；`molihua-v2-{s,a,t,b}.wav`；slug `demo-molihua`；种子 `seed_practice_molihua.php` / `_gen_molihua_stems.py`
- **旧演示**：3 首正弦波 WAV（`practice_demo_p0`）仍保留，`menu_order` 往后排；归档 `orderby menu_order ASC`
- **归档 UI**：引导文案 + 示范卡 `is-featured` /「示范曲」角标
- **归档桌面抛光（2026-07-28）**：`assets/practice.css` `@media (min-width:769)` — 宽 1100px、双列网格、featured 通栏、CTA 酒红胶囊、灰底/藏页脚小工具；曾加 logo `::after "练习"` **已按产品去掉**（主标题区已有「练习」），勿再加回；critical + practice.css 显式 `content:none!important` 防刷新 FOUC；移动保持单列；样式只在 practice.css
- **桌面 logo 居中（2026-07-28）**：同公告——`space-between` + 空壳 + absolute `.header-user` 把 logo 挤中间。修：`flex-start`、藏 `menu-icon/mobile-box/site-opt`、user absolute 右贴；部署 `_deploy_practice_css.py`
- **归档全套抛光（2026-07-28 · 选项 5）**：
  1. 桌面根页藏重复 H1（`.title--sr`；分类页仍显示）
  2. 元信息改芯片；示范曲通栏+浅粉底更强；同页 `usort` 把 featured 置顶（认知脚本会把演示曲 menu_order 甩到末尾）
  3. 引导条《茉莉花》可点 → `/practice/demo-molihua/`
  4. 桌面实心 `--b2-list-bg`（对齐公告快捷频道）；藏 `.site-footer-widget-in`
  - 部署：`_deploy_practice_archive_polish.py`（css + archive-practice.php）
- **P1 已上线（2026-07-29）**：
  1. **变速** `0.5 / 0.75 / 1 / 1.25 / 1.5×`（`BufferSource.playbackRate`；会变调，属浏览器原生限制）
  2. **耳返录音**：`getUserMedia` + `MediaRecorder`；可选耳返监听；录完试听/下载 webm|m4a；录音时自动起播伴奏
  3. **打卡到声场**：复制文案（曲名+速度+链接）并打开声场（优先 `circle_tags`「交流」/slug `exchange`，否则 `/circle/`）
  - 模板工具区：`.b2-practice-tools`；localize 增 `circleCheckinUrl` / `permalink`
- **P1 仍未做 / 内容侧**：真人分轨曲库替换合成 WAV、会员解锁、不改调的时间拉伸、声场 API 直发帖
- **后台**：编辑练习曲 → meta box「声部轨」填 URL；真分轨上线后替换演示 WAV 即可
- **乐谱联动（2026-07-24）**：列表「可练习」角标 + 筛选 `score_practice` + 详情 CTA 已上线；见 `score_practice_link_dev_memory.md`（示范《茉莉花》5574↔5572）
- **坑**：点乐谱「可练习」筛空 = 默认按浏览排序 + 无 `views` meta；已全站公开内容 views 保底（`b2child_ensure_post_views` + `_backfill_all_views.php`）
- **用户指南（2026-07-24）**：练习说明已并入产品手册《内容怎么看》`4688`；旧文 `5597` 为跳转 stub；快捷频道卡 `sc_practice.md` 已写 P1 能力
- **注意**：服务器无 ffmpeg；WAV 本地 Python 生成后上传；`content-type` 可能是 octet-stream，decodeAudioData 仍可用
