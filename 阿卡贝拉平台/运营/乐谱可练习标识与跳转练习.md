# 乐谱可练习标识与跳转练习

## 开发要点
- **产品**：有分轨音频的乐谱 → 列表角标「可练习」+ 行脚「去练习」；筛选维度 `练习|score_practice|可练习`；详情顶栏 CTA「开始练习」进 `/practice/{slug}`
- **关联**：practice meta `_b2_practice_linked_score_id`；乐谱 meta `_b2_score_practice_id` + `score_practice=可练习`；保存练习曲时 `b2child_practice_set_linked_score()` 双向同步
- **前台 map**：`window.b2ScorePracticeMap[scoreId]={id,url,title}`（`b2child_localize_score_practice_map`）；列表 `enhanceScoreRow` 读 `tr#item-{id}`
- **示范内容（2026-07-24）**：乐谱 `5574`《茉莉花》↔ `5572`；**OMR P0 八首已挂可练习**：Deck the Hall `4301`、至少还有你 `703`、知足 `785`、当 `708`、心墙 `735`、Happy Birthday `4313`、Without U `4347`、九儿 `4353`（练习 `omr-score-{id}` / `5631–5638`，分轨 `uploads/practice-omr/score-{id}/`）
- **用户文档（2026-07-24）**：练习说明并入手册《内容怎么看》`4688`；`5597` 为 stub；本地 `_ops_pack/docs/practice_and_score_guide.md` + `handbook/04_content.md`
- **筛选**：score 分类 `b2_filter[0].meta` 已追加练习行；URL `?score_practice=可练习`
- **快捷按钮（2026-07-25）**：放在**搜索栏右侧工具条**（搜索｜可练习｜排序｜筛选），`b2-score-practice-quick`；点开/再点关 `?score_practice=可练习`；**勿放横滑芯片行**；原「练习」下拉不动（`insertScorePracticeToolbarQuick`）
- **快捷样式**：默认白底+浅描边（对齐排序/筛选 `fliter-button`）；选中酒红浅底+描边+字重 600。曾试灰底对齐芯片，已按产品要求恢复白底。
- **列表 CTA 位（2026-07-26）**：「去练习」在 `.post-6-title` 内紧贴标题（非 meta、非行最右）；见 `score_mobile_dev_memory`
- **详情 CTA（2026-07-26）**：正文前 `b2-score-practice-cta`「开始练习」；`the_content` priority 12；无关联不插。示范 `5574.html` → `/practice/demo-molihua`
- **坑（2026-07-24）**：乐谱默认 `post_order=views`；父主题 `meta_key=views` INNER JOIN，无 views meta 会被筛空。已全站 views 保底
- **现状**：可练习 = 茉莉花示范 + OMR 八首合成分轨试听（Choir Aahs，非真人）；发布脚本 `_score_omr_publish_practice.py`
