# 练习与乐谱使用说明（运营稿）

# 练习频道与可练习乐谱（用户指南）

> 站内正式文档已发布到「平台指南」。本文为本地备份，便于改稿。

## 一分钟搞懂

- **乐谱页**：看 PDF 谱面；筛选「可练习」找有分轨音频的曲
- **练习页**：多轨播放器（静音 / 独奏 / 音量 / A-B），跟唱自己的声部
- 两者用「开始练习 / 去练习 / 查看乐谱」互跳

## 进入练习

1. 快捷入口「练习」或打开 `/practice/`
2. 优先试带「示范曲」角标的条目（《茉莉花》SATB）
3. 手机上先点「点击开始练习」才能出声

## 练习工具

| 功能 | 用途 |
|---|---|
| 播放/暂停、进度条 | 整首控制与定位 |
| 静音 Mute | 关掉自己的声部，听其余合声 |
| 独奏 Solo | 只听某一声部学旋律 |
| 音量 | 单轨大小 |
| A-B 循环 | 反复练难小节 |

推荐：Solo 自己的声部 → Mute 自己的声部合练 → 全开检查。

## 可练习乐谱

1. `/category/score` → 筛选 **练习 → 可练习**
2. 列表「可练习」角标 / 「去练习」
3. 乐谱详情顶栏「开始练习」

示范：乐谱《茉莉花（SATB·可练习）》↔ `/practice/demo-molihua`

## 看谱 + 分轨配合

- 电脑：一窗谱、一窗练习器
- 手机：先认谱与声部，再进练习；卡壳处用 A-B

## FAQ

- 没声音 → 未点「开始练习」或系统静音
- 无「可练习」→ 该谱尚未挂分轨
- 音色偏合成 → 教学示范轨，真人分轨会陆续替换
