# 排练闭环 P0 交付（曲库·开排筛·本周练·招新·歌单）

## 开发要点
- **口径**：P0 五件事已上线产品能力；**真人分轨音频**仍靠制谱合作替换合成分轨（质量标 `real|synth|demo`）。现有可练 9 首：茉莉花示范 + OMR 八首热曲（合成分轨可练）。
- **模块**：`_b2child_local/functions-rehearsal-p0.php`（`functions.php` file_exists 载入）
- **1 曲库**
  - meta `_b2_practice_stem_quality`；后台侧栏可改；列表芯片显示质量文案
  - 指南文档 `6216` slug `ke-lianxi-pu-tijiao`《如何提交可练习谱》
  - 种子 `_seed_rehearsal_p0.php`：回填 9 首 score 的 voicepart/difficulty/score_use + 可练习
- **2 开排选型**
  - 乐谱页芯片条 `#b2-score-rehearse-chips-src` → JS `initScoreRehearseChips` 挂到归档
  - URL：`voicepart` / `difficulty` / `score_use`(教学|迎新|赛场|演出|录音) / `score_practice`
  - `filter_tags` `$DIM_ORDER['score']` 改为 声部→难度→用途→练习 靠前；用途 FIXED 含迎新/赛场
- **3 本周练什么**
  - option `b2child_week_practice_id`（默认茉莉花 5572）；练习归档顶栏 `.b2-week-practice`
  - 后台练习曲勾选「设为本周练什么」
- **4 团招新**
  - 乐团单篇 CTA `.b2-band-recruit-cta` → 声场 `campus-bands|cover-collab|exchange` + `?prefill=band_recruit&title&body`
  - JS `initCirclePrefillCompose` 打开发帖框填标题正文
- **5 本周歌单**
  - user meta `_b2_rehearsal_list`；REST `b2child/v1/rehearsal-list`
  - 页 `/rehearsal-list/`；乐谱/练习详情「钉进本周歌单」
- **部署**：`_ops_pack/jobs/_deploy_rehearsal_p0.py`（主题 + seed + filter_tags）
- **诚实边界**：勿对外宣称「已有真人分轨曲库」；UI 标合成分轨/示范；真人上轨后改 quality=`real`
