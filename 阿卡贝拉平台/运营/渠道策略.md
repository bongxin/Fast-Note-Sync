# 渠道策略

## 核心运营理念（必须遵守 · 2026-07-24 用户确认）

> **运维中枢放在自有平台（尤其声场），由智能体对接站内数据，完成分析、自动发布与回复。**  
> **飞书、公众号/订阅号等第三方若当作运维主场，对接与响应会被迫大量人工介入，ROI 低，不做。**  
> **外部渠道（朋友圈、群、B站等）只负责获客触达，把人带进站；分析 / 发布 / 回复尽量只在站内完成。**

**全日讨论定稿报告（用户要求妥善归档）**：`ops_discussion_report_20260724_dev_memory.md`

### 理念拆解
1. **声场 = 可自动化的运营主场**：Agent 可读帖/评/用户，可发帖、跟帖、巡检——闭环不断在「复制到别的 App」。
2. **AI 降低的是「站内运维」成本**，不是「把运维搬去飞书/订阅号」的借口；内容日历、反馈看板、数据表的目标态是站内数据 + Agent，不是先建飞书中枢。
3. **服务号 ≠ 内容号**：服务号只做微信登录基建，降低注册门槛；不强迫日更。
4. **小程序 = 信任壳，不是运维面（用户补充 2026-07-24）**
   - **痛点**：相对第三方 App / 小程序，纯网页访问存在「信任薄弱」（陌生域名、像钓鱼、难再找、微信外打开门槛高）——此顾虑成立，可作为做小程序的**独立理由**。
   - **边界**：小程序解决的是**入口信任与微信内可达性**；**运维中枢仍在站内声场 + Agent**，不因小程序改回「多平台人工运维」。
   - **推荐形态（若做）**：**轻壳 / 同源**——web-view 或同一套 API 读同一 WordPress 数据；声场发帖/回复仍落库站内，Agent 脚本无需双写飞书或另套内容库。
   - **不推荐**：为信任感重做一套独立小程序内容库与运营后台（会破坏智能体闭环理念）。
   - **时机**：可在「企微/群承接 + 声场节奏」跑通后启动调研；信任缺口若已明显阻碍转化（朋友圈点开不敢登、留存差），可提前排期轻壳方案。
5. **朋友圈 / 群**：钩子与承接；动作落到站内具体页或声场（或未来小程序同一入口），而非在外部平台养第二套运营流程。

## 渠道优先级（修订）
1. **声场 Agent 闭环**（分析 → 发布/回复 → 记记忆）
2. 企微 + 1～2 群（仅承接朋友圈漏斗）
3. 朋友圈作钩子 → 站内（或未来小程序轻壳同一后端）
4. 服务号维持登录；订阅号 / 飞书运维中枢 = 缓或不做
5. B站/小红书：外发回流，非运维脑
6. **小程序（可选）**：为信任与微信入口；轻壳同源，不做第二运维中枢
7. **抖音系（用户问 2026-07-24）**：**考虑获客，不把运维中枢搬过去**
   - **做**：官方抖音号发/转站内优质短视频；简介+置顶导回站或小程序；团入驻时收集抖音号（已有能力）；站内继续嵌入/日更抓取（B站为主、抖音 best-effort）
   - **缓/不做（冷启动）**：抖音小程序、抖音企业号重度运营、抖音评论区当客服主场、抖音本地生活/直播带货矩阵；阶段一已明确**跳过**抖音评论区 AI 解析
   - **原因**：阿卡贝拉有短视频爆发力，适合引流；但评论互动与私信难被站内 Agent 闭环，易变第二套人工运维，违背「声场+智能体」理念

## 微信账号认证费用备忘（2026-07 口径，以支付页为准）
- **服务号 / 小程序**：企业主体微信认证约 **300 元/次·年**；个体工商户/个人主体小程序常有 **30 元** 优惠档（限时，以页面为准）；政府等少数类型免费。失败不退。
- **二者分开认证、分开年审**；已认证服务号可用「复用资质快速注册小程序」**免小程序首次认证费**，初始有效期对齐服务号，**次年小程序仍须独立年审付费**。
- **企微**：基础功能可免费用；小规模企业认证约 **300 元/年**（中大型按规模更高）。**非微信强制必开**，属运营承接建议；未认证时外部客户/人数上限会收紧。
- **不算进认证但常一起发生**：域名已有则 ICP/小程序备案多为时间成本；开放平台网站应用若单独验主体另计；云服务器/开发人力另计。
