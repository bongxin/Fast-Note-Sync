# 分类页默认排序（内容最新·目录浏览）

## 开发要点
- **原则**：不为全站默认「随机」；随机保留在下拉里。
- **默认映射**
  - `video` / `short` / `quality` / `tutorial` / `saishi`（含子类）→ `post_order=new`（最新）
  - `score` / `band` / `musicians` / `organization`（含子类）→ `post_order=views`（最多浏览）
  - 其它分类 → `new`
- **实现**：`b2child_category_default_post_order` @ `template_redirect` priority 1；仅当 URL 无 `post_order` 时注入 `$_GET`/`$_REQUEST`，覆盖分类 `b2_group` 里可能写死的 random。
- **父主题**：排序按钮值 `new|random|views|like|comments`；`Posts.php` 对 `new` 不改 orderby（按日期）；空参 UI 文案易显示「排序」，故内容流显式注入 `new`。
- **乐谱**：原 `b2child_score_default_order_views` 并入通用函数；旧函数名保留为包装。

- `_b2child_local/functions.php`
