# 快捷入口 · 公告

官方通知：维护、政策、活动与平台动态。

## 入口

- 顶栏快捷入口「公告」
- URL：`/announcement`

## 这个频道做什么

发布需要全体用户知晓的正式信息。例如系统维护、规则更新、入驻开放、周报类官方汇总。请以公告正文为准。

## 页内怎么用

- 列表按日期浏览；点进阅读全文
- 重要公告可能在首页个人信息面板摘要露出，完整内容仍以公告频道为准

## 和相邻频道的区别

| 频道 | 差异 |
|------|------|
| 公告 | 官方、偏正式与时效 |
| 快讯 | 社区速报与线索，语气更轻 |
| 文档 | 长期有效的使用说明 |
