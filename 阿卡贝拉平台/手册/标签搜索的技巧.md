# 标签搜索的技巧

> 站内「找内容」不只靠关键词。分类页的多维标签筛选，往往比搜曲名更快、更准。

## 三种「标签」别混

| 类型 | 在哪 | 做什么 |
|------|------|--------|
| **分类筛选标签** | 视频 / 短视频 / 乐团 / 乐谱 / 赛事 / 音乐人等分类顶栏 | 按维度收窄列表（本文重点） |
| **文章标签云** | 页脚标签云 · `/tags` 全部标签 | 点一个标签看全站相关文 |
| **兴趣标签** | 登录后引导 / 个人中心 | 影响搜索里的「为你推荐」，不是列表筛选 |

## 怎么打开筛选

1. 先进入对应分类（如「视频」「乐谱」「乐团」）
2. **手机**：工具条点「筛选」→ 右侧抽屉里点选 → 底部「确定」
3. **电脑**：工具条点「筛选」展开面板；再点可收起（会记住你的习惯）
4. 已选数量会显示在「筛选」旁角标；「重置」清空后回到该分类全部

同一维度一般单选；**不同维度可以叠选**（结果取交集，越选越少）。

## 组合示例（直接照着用）

- **找混声翻唱横屏成片**：视频 → 作品类型「翻唱」+ 人声组合「混声」+ 视频方向「横屏」
- **找抖音竖屏短视频**：短视频 → 平台「抖音」（或作品类型「直拍」等）
- **找高校活跃乐团**：乐团 → 团体类型「高校团体」+ 动态「活跃」；需要可再加首字母
- **找入门可练习谱**：乐谱 → 难度「入门」+ 练习「可练习」（或工具条旁「可练习」快捷）
- **找四声部中文流行谱**：乐谱 → 声部结构「SATB」+ 语种「中文」+ 风格「流行」
- **找某城音乐人**：音乐人 → 地区「上海」等 + 核心角色（如 Beatbox）

结果为空时：先去掉最后一个维度，或换相近标签（例如「混声」↔「男声」）。

## 各频道常用维度（记关键词即可）

- **视频**：作品类型 · 录制类型 · 人声组合 · 语言 · 视频方向（横/竖）
- **短视频**：平台（抖音/B站…）· 作品类型 · 人声组合 · 语言
- **乐团**：团体类型 · 合唱声部 · 首字母 · 年份 · 动态
- **乐谱**（多为字段筛选，不是普通文章标签）：声部结构 · 难度（入门/进阶/高阶）· 人声组合 · 语种 · 风格 · 用途 · 谱面格式 · **可练习** · 改编 / 演唱
- **赛事**：类型 · 年份 · 状态 · 赛程 · 地区
- **音乐人 / 机构**：角色或组织类型 · 地区 · 所属乐团 / 机构等

子分类（如视频下的「精选 / 作品 / 教程」）在「分类」行切换，可与标签叠加。

## 和关键词搜索怎么配合

1. **先筛选再搜**：分类页收窄范围后，再用顶栏/分类内搜索框搜曲名、团名
2. **关键词搜不到时**：多半是词太窄或类型 Tab 不对 → 改用标签组合，或到 `/tags` 点相关标签
3. **搜人 / 搜团**：搜索类型选「用户」，团名或昵称；资料页之外再用乐团分类标签浏览

## 小技巧

- 维度按「先定硬条件、再加偏好」：声部 / 平台 / 难度这类先选，风格、年份后选
- 乐谱难度：入门≈少声部或简易曲；常规四声部多为进阶；五声部及以上或复杂编制多为高阶
- 页脚标签云偏热门实体；要系统浏览用分类筛选，不要只靠云里的字母/年份词
- 「全部标签」入口：页脚标签云标题旁，或直接打开 `/tags`

## 常见问题

- **选了好几个没结果？** 交集过窄，去掉一维或换分类再试  
- **乐谱筛选项和视频不一样？** 正常：乐谱用声部/难度等字段；视频用作品类型等标签  
- **兴趣标签勾了列表却不变？** 兴趣只影响「为你推荐」，请到对应分类用筛选条  
- **想收藏这条组合？** 浏览器收藏当前带筛选参数的 URL 即可下次打开
