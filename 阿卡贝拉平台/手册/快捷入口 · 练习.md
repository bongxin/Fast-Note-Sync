# 快捷入口 · 练习

多轨声部练习器：按声部跟唱、A-B 循环，可同页看谱。

## 入口

- 顶栏快捷入口「练习」
- URL：`/practice/`
- 乐谱列表筛「可练习」也可跳进练习器

## 这个频道做什么

把「可练习」乐谱挂上分轨音频后，在浏览器里分轨练声部。这是平台差异化工具页，不是内容信息流。

## 页内怎么用

- 归档挑曲（示范曲有角标）；单曲页可折叠「曲目信息 / 分轨练习 / 乐谱」
- 手机须先点「点击开始练习」才能出声
- 支持静音 / 独奏 / 音量 / 进度 / A-B / **变速（0.5–1.5×）**；有关联谱时可「看谱」嵌 PDF（不跳页）
- **耳返录音**：开麦克风跟唱，可开耳返听自己；录完可试听/下载
- **打卡到声场**：一键复制文案并打开声场发帖
- 需要看完整乐谱详情时，可新开「乐谱详情」
- 注意：变速会连带变调（浏览器原生能力）；精修不改调属后续能力

## 和相邻频道的区别

| 频道 | 差异 |
|------|------|
| 练习 | 分轨跟唱工具 |
| 乐谱分类 | 谱面库与筛选（主导航） |
| 文档「曲谱资源」 | 说明与曲集介绍，不是播放器 |
