# 快捷入口 · 文档

帮助中心：平台指南、教程、乐理、行业观察与曲谱资源说明。

## 入口

- 顶栏快捷入口「文档」
- URL：`/document`
- 平台指南：`/document/pingtaizhinan`

## 这个频道做什么

查「这个页面怎么用」、产品手册、教程与资料索引。右下角「贝拉」也可问答；活问题与功能想法请走声场「回响·反馈」。

## 页内怎么用

- 归档：分类卡片（平台指南 / 教程指南 / 行业观察 / 乐理科普 / 曲谱资源）+ 「最新文档」列表
- 点进分类可看二级芯片与篇目；产品手册在「平台指南 → 产品手册」
- 单篇页有目录与同组文章；部分曲谱说明含 PDF 预览

## 和相邻频道的区别

| 频道 | 差异 |
|------|------|
| 文档 | 官方说明与知识库 |
| 公告 | 时效性官方通知 |
| 导航 | 站外友链与资源导航 |
| 教程分类（主导航） | 内容流教程文章，非手册壳 |
