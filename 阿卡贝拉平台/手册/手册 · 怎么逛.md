# 手册 · 怎么逛

# 浏览与发现（v3）

首页/分类、搜索、兴趣推荐、导航、文档中心。

## 入口

- 首页；顶栏搜索
- 导航（友情链接）；文档中心 / 平台指南

## 要点

- 搜索结果切换类型 Tab
- 登录后勾选兴趣标签 →「为你推荐」
- 分类页多维标签筛选（手机抽屉 / 电脑「筛选」）→ 见专篇《标签搜索的技巧》
- 文档：平台指南（手册）｜教程｜乐理｜行业｜曲谱

## FAQ

- 搜不到 → 换词或换类型；或用分类标签组合
- 推荐不准 → 重选兴趣
- 标签筛选详解 → `handbook/tag_search_tips.md` / 线上 `/document/6132.html`
