# 快捷入口 · 声场

站内社区：招新、排练讨论、演出预告与主题聊天。

## 入口

- 顶栏快捷入口「声场」
- URL：`/circle`
- 反馈共建：`/circle/feedback`（回响·反馈）

## 这个频道做什么

人声爱好者的圈子主场。一团建议维护一个主声场，置顶招新与演出信息；日常闲聊、约排练、听感分享都在这里。

## 页内怎么用

- 逛广场看最新 / 热门话题；进具体圈子浏览与发帖
- 可发文字、图片、音视频话题
- 使用问题与功能需求请发到「回响·反馈」，标题可带【使用问题】或【功能需求】
- 创建圈子权限与等级 / VIP 有关，以页面提示为准

## 和相邻频道的区别

| 频道 | 差异 |
|------|------|
| 声场 | 即时讨论与圈子动态 |
| 专栏 / 文章 | 可归档的长图文 |
| 快讯 | 短讯速报，非讨论串 |
