# 快捷入口 · 快讯

站内「今日人声」速报频道：演出、活动、作品、赛事、快报与招募。

## 入口

- 顶栏快捷入口「快讯」
- URL：`/newsflashes`

## 这个频道做什么

用短讯把站内外人声动态及时推到前台。适合扫一眼「最近发生了什么」，不是写长文的地方。

## 页内怎么用

- 顶部分类芯片：演出 / 活动 / 作品 / 赛事 / 快报 / 招募
- 排序：发布时间（默认）或活动时间
- 「我要爆料」可提交线索（登录后按页面提示）
- 点进单条可读全文；快报常带站内链汇总

## 和相邻频道的区别

| 频道 | 差异 |
|------|------|
| 快讯 | 短讯速报、时间线 |
| 公告 | 官方通知、维护与政策 |
| 专栏 | 成体系的文章合集 |
| 声场 | 圈子讨论与招新闲聊 |
