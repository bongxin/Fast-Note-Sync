# 快捷入口 · 专栏

成体系的文章合集（专题 / 系列），不是单篇信息流。

## 入口

- 顶栏快捷入口「专栏」
- URL：`/collection`

## 这个频道做什么

把相关文章收成「专栏 / 合集」来读：教程系列、主题策展、连载等。适合按主题深读，而不是按发布时间刷首页。

## 页内怎么用

- 浏览合集列表；点进合集看目录与篇目
- 合集内文章仍是站点文章，可分享单篇链接
- 筛选 / 分类以页内芯片为准（与主导航文章分类不同入口）

## 和相邻频道的区别

| 频道 | 差异 |
|------|------|
| 专栏 | 合集容器 + 系列阅读 |
| 首页 / 主导航分类 | 单篇信息流（短视频、乐谱等） |
| 文档 | 产品说明与指南，非策展内容 |
