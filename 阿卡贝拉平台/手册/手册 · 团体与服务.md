# 手册 · 团体与服务

# 团体与服务（v3）

词条认领、工作室挂单；**入驻开放**见站内文档《团/组织如何入驻》。

## 入口

- 乐谱 / 乐团 / 音乐人 / 组织分类词条页 →「认领此页」
- 认证中心；`/shop`
- 入驻总指南：平台指南 →《团/组织如何入驻》
- 公告：【新功能】词条认领上线

## 要点

- **页内认领（推荐）**：打开已有词条 → 认领此页 → 填角色与证明 → 审核通过后可维护资料；列表封面显示「已认领」
- **人数**：音乐人仅 1 人；乐团 / 组织 / 乐谱可多人
- **高校社 / 社会团建档**：站内尚无页时，按《团/组织如何入驻》建档 + 证明；建档后仍可用页内认领绑定维护者
- 创作者：认证中心 → 发作品；工作室挂单当前客服代发
- 可选：导航「申请入驻」友链

## FAQ

- 认领被拒 → 补材料再提
- 音乐人页显示「已被认领」→ 槽位已满，可联系原维护者退出后再申请
- 自助上架工作室挂单 → 后续开放，当前代发
- 材料字段（建档）→ 团名、类型、城市/高校、联系人、社媒链接、是否已有站内页
