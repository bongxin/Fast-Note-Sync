# 快捷入口 · 导航

人声相关站外链接与资源导航（友情链接）。

## 入口

- 顶栏快捷入口「导航」
- URL：`/links`（或站点配置的 links 归档）

## 这个频道做什么

把站外优质资源（教材站、谱库、活动页、社群等）集中陈列，方便跳转。不是站内文章，也不替代文档中心的产品说明。

## 页内怎么用

- 按分类芯片浏览链接卡片
- 每条通常含标题与简短描述；点击出站
- 申请入驻 / 友链以页内或公告说明为准

## 和相邻频道的区别

| 频道 | 差异 |
|------|------|
| 导航 | 站外链接目录 |
| 文档 | 站内说明与手册 |
| 专栏 | 站内文章合集 |
