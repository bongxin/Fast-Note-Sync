# 入驻触达周更钩子与私信包

## 开发要点
- **原则**：只生成清单 + 可复制话术；**人工**发 B 站/企微；禁止脚本自动私信/群发。
- **周次**：`config/recruitment_weeks.json`；`anchor_monday=2026-07-27`；第1周=高校8+社会5；共 4 周。
- **输出**：`queue/recruitment/{ISO周}/this_week.md` + `checklist.json`；指针 `LATEST.md`；状态 `state/recruitment_weekly.json`
- **本机**：跑钩子时写入 Obsidian `阿卡贝拉平台/入驻触达/周更私信包/` + `入驻触达 · 本周私信包.md`
- **定时**
  - 服务器：`all_weekly`（周一 03:00）含 `recruitment_hook`；另周一 **09:00** 单独 `recruitment_hook`
  - 本机：计划任务 `BERNSINE_RecruitmentWeekly` 周一 09:00 → `_run_recruitment_weekly_local.bat`
- **手动**：`python jobs/recruitment_weekly_hook.py` 或 `--week N`；服务器 `run.sh recruitment_hook`
- **部署**：`_deploy_recruitment_weekly_hook.py`；装本机任务 `_install_recruitment_weekly_task.py`

## 改动涉及的文件
- `_ops_pack/config/recruitment_weeks.json`
- `_ops_pack/jobs/recruitment_weekly_hook.py`
- `_ops_pack/run.sh` / `crontab.fragment` / `install_cron.sh`
- `_ops_pack/jobs/_deploy_recruitment_weekly_hook.py`
- `_ops_pack/jobs/_install_recruitment_weekly_task.py`
- `_ops_pack/docs/recruitment_outreach_copy.md`
- 服务器 `/root/acappella-ops/**`
